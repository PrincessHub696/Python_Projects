# Feedback Site

Сайт с формой обратной связи на Flask.

## Функционал

- Форма с полями: имя, email, сообщение
- Отправка данных на сервер (POST)
- Страница благодарности с именем пользователя

## Как запустить

1. Установи Python 3.
2. Установи Flask:

```
pip install flask
```

3. Запусти:

```
python app.py
```

4. Открой в браузере: http://127.0.0.1:5000/

## Технологии

- Python 3
- Flask
- HTML/CSS
- Формы (GET/POST)
