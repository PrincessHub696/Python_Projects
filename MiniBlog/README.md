# Mini Blog

Мини-блог с базой данных SQLite.

## Функционал

- Добавление поста (заголовок, текст, дата)
- Просмотр всех постов
- Удаление поста по ID

## Как запустить

1. Установи Python 3.
2. Запусти программу:

```
python blog.py
```

3. Выбери действие в меню.

## Технологии

- Python 3
- База данных SQLite (`sqlite3`)
- Модуль `datetime`
