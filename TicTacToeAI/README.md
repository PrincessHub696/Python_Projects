# Tic Tac Toe AI

Игра "Крестики-нолики" против компьютера с искусственным интеллектом.

## Функционал

- Игрок играет за X, компьютер за O
- Компьютер блокирует ходы игрока
- Компьютер занимает центр и углы
- Проверка победы и ничьей

## Как запустить

1. Установи Pyrhon 3.
2. Скачай файл `tic_tac_toe_ai.py`
3. Запусти его:

```
python tic_tac_toe_ai.py
```

## Технологии

- Python 3
- Вложенные списки
- Функции
- Логика ИИ
