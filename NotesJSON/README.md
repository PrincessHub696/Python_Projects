# Notes with JSON

Программа для создания и хранения заметок в формате JSON.

## Функционал

- Добавление заметки (заголовок + текст)
- Просмотр всех заметок
- Сохранение заметок в файл `notes.json`
- Загрузка заметок из файла

## Как запустить

1. Установи Python 3.
2. Запусти программу:

```
python notes_json.py
```

3. Выбери действие в меню.

## Технологии

- Python 3
- Модуль `json`
- Работа с файлами
