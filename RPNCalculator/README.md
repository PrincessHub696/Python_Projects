# RPN Calculator

Калькулятор для вычисления выражений в обратной польской записи (ОПЗ).

## Функционал

- Вычисляет выражения вида `2 3 +` (результат 5)
- Поддерживает операции: `+`, `-`, `*`, `/`
- Использует стек для вычислений

## Как запустить

1. Установи Python 3.
2. Запусти:

```
python calculator.py
```

3. Введи выражение в ОПЗ.

## Пример

Ввод: `2 3 + 4 *`
Вывод: `Результат: 20`

## Технологии

- Python 3
- Стек (список)
- Обратная польская запись
