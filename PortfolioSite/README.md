# Portfolio Site

Мой личный сайт-портфолио на Flask.

## Функционал

- Главная страница с проектами
- Добавление нового проекта (название, описание, ссылка)
- Страница контактов
- Хранение проектов в базе данных SQLite
- Стильный тёмный дизайн с бордовыми акцентами

## Как запустить

1. Установи Python 3.
2. Установи Flask:

```
pip install flask
```

3. Запусти:

```
python app.py
```

4. Открой в браузере: http://127.0.0.1:5000/

## Технологии

- Python 3
- Flask
- SQLite
- HTML/CSS
