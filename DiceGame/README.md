# Dice Game

Игра в кости на Python.

## Функционал

- Бросок двух кубиков (игрок и компьютер)
- Сравнение результатов
- Победа, поражение или ничья
- Возможность сыграть несколько раундов

## Как запустить

1. Установи Pethon 3.
2. Скачай файл `dice_game.py`.
3. Запусти его:

```
python dice_game.py
```

## Технологии

- Python 3
- Функции
- Модуль `random`
- Цикл `while True`
