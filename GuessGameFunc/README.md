# Guess Game with Functions

Игра "Угадай число" с использованием функций.

## Функционал

- Генерация случайного числа
- Проверка догадок пользователя
- Подсказки "Больше" или "Меньше"
- Поздравление при угадывании

## Как запустить

1. Установи Python 3.
2. Скачай файл `guess_game_func.py`.
3. Запусти его:

```
python guess_game_func.py
```

## Технологии

- Python 3
- Функции
- Модуль `random`
