# Tic Tac Toe

Игра "Крестики-нолики" для двух игроков.

## Функционал

- Игровое поле 3*3
- Два игрока: X и O
- Проверка победы по строкам, столбцам и диагоналям
- Проверка на ничью

## Как запустить

1. Установи Pyrhon 3.
2. Скачай файл `tic_tac_toe.py`
3. Запусти его:

```
python tic_tac_toe.py
```

## Технологии

- Python 3
- Двумерные списки
- Функции
