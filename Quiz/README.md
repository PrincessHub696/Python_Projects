# Quiz

Простая викторина с вопросами и подсчетом очков.

## Функционал

- 5 вопросов с 4 вариантами ответов
- Подсчет правильных ответов
- Вывод результата в конце

## Как запустить

1. Установи Python 3.
2. Запусти программу:

```
python quiz.py
```

3. Отвечай на вопросы, вводя номер варианта.

## Технологии

- Python 3
- Списки словарей
- Циклы и условия
