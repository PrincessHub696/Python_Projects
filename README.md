# PhoneBook OOP

Простая телефонная книга на Python с использованием классов и методов.

## Функционал

- Добавление контакта
- Удаление контакта
- Поиск контакта по имени
- Показ всех контактов
- Сохранение контактов в файл `phonebook.txt`
- Загрузка контактов из файла

## Как запустить

1. Установи Python 3.
2. Скачай файл `phonebook_oop.py`.
3. Запусти его:

```
python phonebook_oop.py
```

## Технологии

- Python 3
- ООП (классы, методы)
- Работа с файлами
- Обработка ошибок (`try-except`)
