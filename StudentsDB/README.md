# Students Database

Программа для управления базой данных студентов через SQLite.

## Функционал

- Добавление студента (имя, возраст, группа)
- Просмотр всех студентов
- Поиск студента по имени
- Обновление возраста
- Удаление студента

## Как запустить

1. Установи Python 3.
2. Запусти программу:

```
python students_db.py
```

3. Выбери действие в меню.

## Технологии

- Python 3
- База данных SQLite (`sqlite3`)
- SQL-запросы (SELECT, INSERT, UPDATE, DELETE)
