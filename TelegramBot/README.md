# Telegram Bot

Мой первый Telegram-бот на Python с использованием библиотеки `aiogram`.

## Функционал

- `/start` - приветствие
- `/help` - список всех команд
- `/time` - текущее время
- `/date` - текущая дата
- `/roll` - бросок кубика (случайное число от 1 до 6)
- `/coin` - подбрасывание монеты (орел или решка)
- `/joke` - случайная шутка про программистов
- Эхо-ответ на любое сообщение

## Как запустить

1. Установи Python 3.
2. Установи библиотеку `aiogram`:

```
pip install aiogram
```

3. Получи токен у `@BotFather` в Telegram.
4. Вставь токен в переменную `BOT_TOKEN` в файле `telegram_bot.py`.
5. Запусти бота:

```
python telegram_bot.py
```

6. Найди своего бота в Telegram b yfgbib `/start`.

## Технологии

- Python 3
- Библиотека `aiogram`
- Асинхронное программирование (`async`/`await`)
- Модули `datetime` и `random`
