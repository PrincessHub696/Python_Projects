# Telegram Bot

Мой первый Telegram-бот на Python с использованием библиотеки `aiogram`.

## Функционал

- `/start` - приветствие
- `/help` - список всех команд
- `/time` - текущее время
- `/date` - текущая дата
- `/roll` - бросок кубика (случайное число от 1 до 6)
- `/coin` - подбрасывание монеты (орел или решка)
- `/joke` - случайная шутка про программистов
- `/weather` - погода в городе
- Эхо-ответ на любое сообщение

## Кнопки

- ⏰ Текущее время
- 🗓️ Текущая дата
- 🎲 Игра в кубик
- 🪙 Игра в монетку
- 🤡 Шутка
- 🌤️ Погода

## Как запустить

1. Установи Python 3.
2. Установи зависимости:

```
pip install aiogram requests
```

3. Получи токен у `@BotFather` в Telegram.
4. Получи API-ключ на `openweathermap.org`.
5. Вставь токен и ключ в файл `telegram_bot.py`:

```python
BOT_TOKEN = "ТВОЙ_ТОКЕН_ЗДЕСЬ"
WEATHER_API_KEY = "ТВОЙ_КЛЮЧ_ЗДЕСЬ"
```

6. Запусти бота:

```
python telegram_bot.py
```

7. Найди своего бота в Telegram и напиши `/start`.

## Технологии

- Python 3
- Библиотека `aiogram`(Telegram Bot API)
- Библиотека `requests`(для погоды)
- Асинхронное программирование (`async`/`await`)
- Модули `datetime` и `random`
- Кнопки (`ReplyKeyboardMarkup)
