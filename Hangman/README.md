# Hangman

Игра "Виселица" на Python.

## Функционал

- Случайное слово из списка
- Угадывание букв по одной
- 6 попыток
- Проверка победы и проигрыша

## Как запустить

1. Установи Python 3.
2. Скачай файл `hangman.py`.
3. Запусти его:

```
python hangman.py
```

## Технологии

- Python 3
- Списки
- Циклы
- Модуль `random`
