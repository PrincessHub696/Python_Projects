# Hash Phone Book

Телефонная книга на основе словаря (хеш-таблицы).

## Функционал

- Добавление контакта
- Поиск контакта (используется метод `.get()`)
- Удаление контакта (используется метод `.pop()`)
- Просмотр всех контактов (используется метод `.items()`)

## Как запустить

1. Установи Python 3.
2. Запусти:

```
python phonebook_dict.py
```

3. Выбери действие в меню.

## Технологии

- Python 3
- Словари (`dict`)
- Методы хещ-таблиц
