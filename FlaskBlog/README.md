# Flask Blog

Блог на Flask с базой данных SQLite.

## Функционал

- Просмотр всех постов
- Добавление нового поста (заголовок + текст)
- Хранение постов в базе данных

## Как запустить

1. Установи Python 3.
2. Установи Flask:

```
pip install flask
```

3. Запусти:

```
python app.py
```

4. Открой в браузере: http://127.0.0.1:5000/

## Техонологии

- Python 3
- Flask
- SQLite
- HTML
