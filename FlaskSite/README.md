# Flask Site

Простой сайт на Flask с тремя страницами.

## Функционал

- Главная страница
- Страница "Обо мне"
- Страница "Контакты"
- Навигация между страницами

## Как запустить

1. Установи Python 3.
2. Установи Flask:

```
pip install flask
```

3. Запусти:

```
python app.py
```

4. Открой в браузере: http://127.0.0.1:5000/

## Технологии

- Python 3
- Flask
- HTML
