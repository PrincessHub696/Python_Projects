# Calculator with History

Калькулятор, который сохраняет историю последних операций в файл.

## Функционал

- Сложение, вычитание, умножение, деление
- Сохранение истории операций в файл `history_calculator.txt`
- Просмотр последних 5 операций

## Как запустить

1. Установи Python 3.
2. Скачай файл `calculator_history.py`.
3. Запусти его:

```
python calculator_history.py
```

## Технологии

- Python 3
- Функции
- Работа с файлами
- Обработка ошибок (`try-except`)
