# Password Generator

Программа для генерации случайных паролей.

## Функционал

- Генерация пароля заданной длины
- Использование букв, цифр и специальных символов

## Как запустить

1. Установи Python 3.
2. Скачай файл `password_generator.py`
3. Запусти его:

```
python password_generator.py
```

## Технологии

- Python 3
- Модули `random` и `string`
