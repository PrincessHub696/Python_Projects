# Site Parser

Программа для получения курса доллара с сервера ЦБ РФ.

## Функционал

- Получает актуальный курс доллара
- Использует JSON-API Центробанка

## Как запустить

1. Установи Python 3.
2. Установи библиотеку `requests`:

```
pip install requests
```

3. Запусти программу:

```
python parser.py
```

4. Программа выведет курс доллара.

## Технологии

- Python 3
- Библиотека `requests`
- Модуль `json`
