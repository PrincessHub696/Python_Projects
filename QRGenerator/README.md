# QR Code Generator

Программа для создания QR-кодов из текста или ссылок.

## Функционал

- Принимает текст или ссылку от пользователя
- Создает QR-код
- Сохраняет его как изображение `qrcode.png`

## Как запустить

1. Установи Python 3.
2. Установи библиотеку `qrcode`:

```
pip install qrcode pillow
```

3. Запусти программу:

```
python qr_generator.py
```

4. Введи текст или ссылку - QR-код сохранится в папке.

## Технологии

- Python 3
- Библиотека `qrcode`
- Библиотека `pillow`
