# Text Analyzer

Программа для анализа текста: подсчет слов и символов.

## Функционал

- Подсчет количества слов
- Подсчет количества символов (без пробелов)
- Вывод результатов

## Как запустить

1. Установи Python 3.
2. Скачай файл `text_analyzer.py`
3. Запусти его:

```
python text_analyzer.py
```

## Технологии
- Python 3
- Строки
- Функции
