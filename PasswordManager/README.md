# Password Manager

Программа для хранения паролей в зашифрованном виде.

## Функционал

- Добавление паролей (сайт, логин, пароль)
- Просмотр сохраненных паролей
- Шифрование через библиотеку `cryptography`

## Как запустить

1. Установи Python 3.
2. Установи библиотеку `cryptography`:

```
pip install cryptography
```

3. Запусти программу:

```
python password_manager.py
```

4. Выбери действие в меню.

## Технологии

- Python 3
- Библиотека `cryptography`
- Модуль `json`
- Модуль `os`
