# ToDo List (С функциями)

Простая программа для управления списком задач с сохранением в файл.

## Функционал

- Добавление задачи
- Удаление задачи
- Показ всех задач
- Сохранение задач в файл `todo.txt`
- Загрузка задач из файла

## Как запустить

1. Установи Python
2. Скачай файл `todo_list_func.py`
3. Запусти его:
```
python todo_list_func.py
```

## Технологии

- Python 3
- Функции
- Работа с файлами
- Обработка ошибок (`try-except`)
