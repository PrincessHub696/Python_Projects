# Socket Chat

Простой чат между сервером и клиентом через сокеты.

## Функционал

- Сервер принимает подключения
- Клиент подключается к серверу
- Обмен сообщениями в реальном времени

## Как запустить

1. Установи Python 3.
2. Запусти сервер:

```
python server.py
```

3. Открой второй терминал и запусти клиент:

```
python client.py
```

4. Пиши сообщения в клиенте - сервер будет отвечать.

## Технологии

- Python 3
- Модуль `socket`
- TCP-соединение
